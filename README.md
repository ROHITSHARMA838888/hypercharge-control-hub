**HyperCharge Control Hub** is the official Android companion controller app engineered and developed by **Rohit Sharma** to manually manage and monitor the **Hyper Charging+ [Rohit Rebuild Edition]** KernelSU / Magisk root module.

---

## 📢 Upstream & Source Attribution

> **Credit & Upstream Base:**  
> The underlying charging governor is a rebuild of [Hyper-Charging-Plus](https://github.com/Demonx4y/Hyper-Charging-Plus) created by **[@Demonx4y](https://github.com/Demonx4y)**.  
> While the original project provided the core Linux sysfs engine, **Rohit Sharma** designed and programmed this Android application from scratch to give users a sleek, animated, and instant manual mode-switching dashboard with live hardware telemetry.

---

## ✨ Features

* **⚡ Animated Splash Screen:** Featuring glowing charge bolt animations and explicit developer & base credits.
* **🎛 Manual Mode Switcher:**
  * ⚡ **Ultra Turbo Mode** (6.0A Peak Speed — ideal with phone coolers)
  * ⚖️ **Balanced Mode** (4.5A Fast Charge — daily optimal use)
  * 🛡️ **Eco Mode** (2.5A Cool Charge — protects battery longevity)
  * 🎮 **Gaming Bypass Mode** (0.5A Idle Charge — stops phone overheating during games)
  * 🔄 **Auto Governor** (Adaptive dynamic thermal ladder)
* **📊 Live Battery & Charging Telemetry:**
  * Real-time Battery Percentage
  * Live Battery Temperature (°C) with dynamic color thresholds
  * Current Flow (mA) & Charging Voltage (V)
* **🔄 Built-In In-App OTA Updater:**
  * Directly queries GitHub Releases API for instant 1-click updates.
* **📱 Device Compatibility:**
  * 🟢 **Xiaomi Snapdragon (Qualcomm):** 100% Working (POCO F-series, Redmi Note Pro Snapdragon, Xiaomi Flagships)
  * 🟡 **Xiaomi MediaTek (Dimensity):** Partial Support / Safe Fallback (Zero crash guarantee)
